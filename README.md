## Installing

.NET Cli

```sh
dotnet add package QingYi.Core
```

Package Manager

```TEXT
NuGet\Install-Package QingYi.Core
```

Package Reference

Need specific the verison, 6.0.0 is the latest release version.

```xml
<PackageReference Include="QingYi.Core" Version="6.0.0" />
```
